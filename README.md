# Telecom Service Ticket Analytics Dashboard

## Project Overview
An Excel-based dashboard designed to analyze telecom service tickets, monitor support performance, and identify opportunities to improve customer service and operational efficiency.

## Tools
- Microsoft Excel
- PivotTables and PivotCharts
- Interactive Slicers
- Data Visualization

## Key KPIs
- Total Tickets by Region
- Median Resolution Time by Service Type
- Ticket Status Breakdown
- SLA Breach Percentage
- Monthly Ticket Trend
- Customer Satisfaction (CSAT)
- Ticket Volume by Channel

## Business Purpose
To monitor service performance, identify SLA compliance issues, evaluate resolution efficiency, and support data-driven improvements in customer satisfaction.
